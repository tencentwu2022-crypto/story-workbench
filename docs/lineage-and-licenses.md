# Lineage, attribution and license boundary

This repository is an independent implementation. It does not vendor code, prompts, novel text, screenshots or private data from the projects listed below.

| Reference | What was used | License / handling |
|---|---|---|
| [oh-story-claudecode](https://github.com/worldwonderer/oh-story-claudecode) | public workflow concepts such as scan → deconstruct → write → de-AI-ify | The repository declares MIT. This project re-implements the concepts in its own Markdown; no source files are copied. |

No code or prompts are copied; review its current terms before any future reuse. |
| `hy_novel_studio_v2` | the local workflow specification being published here | The 12-stage Markdown skills and templates in this repository are the project’s own release artifacts. |

External references can change. Before copying implementation, prompts, assets or dependencies, re-check the upstream repository, its current license files and any notices. Conceptual similarity alone is not a license to copy expression.

## Data boundary

No unpublished manuscript, chat export, account credential, ranking login or platform dataset belongs in this repository. Market-scan work must use user-supplied or separately verified public material and must record evidence rather than inventing rank, readership or retention data.
