# 爽点与情绪兑现分析器

## 定义

爽点不是“打脸”的同义词，而是此前积累的期待、压抑、信息差或能力差得到有效兑现。

## 爽点事件表

对每个候选事件记录：

- 铺垫起点；
- 读者期待；
- 阻力；
- 兑现事件；
- 见证者；
- 主角付出的代价；
- 结果是否改变局面；
- 是否产生后续问题。

## 类型

- 能力兑现；
- 信息差兑现；
- 身份反差；
- 规则破解；
- 资源获取；
- 反击；
- 夺回主动；
- 关系确认；
- 正义或情绪宣泄；
- 真相揭晓；
- 危机脱出；
- 牺牲获得意义。

## 评分公式（编辑启发式，不是科学指标）

单次兑现分 = 铺垫强度 + 阻力强度 + 结果可见性 + 局面改变 + 情绪释放 - 偶然性 - 解释负担

每项 0—2 分。总分只用于横向比较同一项目章节。

## 低质量爽点

- 配角无理由集体震惊；
- 反派突然降智；
- 主角无代价获得能力；
- 用旁白宣布“所有人都震撼”；
- 重复同一种打脸；
- 爽完后局面没有变化；
- 兑现没有前置期待。
