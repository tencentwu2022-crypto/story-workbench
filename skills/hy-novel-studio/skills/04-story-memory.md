# 长篇小说项目记忆

参考长篇小说生产系统的结构化记忆思想，但使用轻量 Markdown 文件，不依赖特定数据库。

## 信息状态

每条信息标记：

- `CONFIRMED`：作者确认或正文明确成立；
- `PLANNED`：大纲计划，尚未进入正文；
- `RUMOR`：角色听闻，不代表事实；
- `UNKNOWN`：有意保留；
- `RETIRED`：设定已废弃。

## 更新规则

每章完成后更新：

1. 人物当前位置；
2. 人物身体和心理状态；
3. 人物掌握的信息；
4. 新增关系变化；
5. 新增物品、资源和能力；
6. 时间推进；
7. 新埋伏笔；
8. 已回收伏笔；
9. 尚未解决的问题；
10. 下一章必须承接事项。

不得把角色的错误判断写成世界事实。
